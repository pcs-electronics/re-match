# Plan for tt-plot.py Script

## Overview
Create a Python script named `tt-plot.py` to parse Touchstone data from stdin or a file and generate various plots based on the data. The script should support multiple plot types and save the resulting plots to a specified file.

## Key Requirements
1. **Input Handling**: Parse Touchstone data from stdin or a file.
2. **Format Detection**: Automatically detect the Touchstone format (S,RI, S,MA, S,DB, or Z,RI).
3. **Plot Generation**: Generate plots based on the specified type (SWR to 10, SWR to 2, S11, RX to 1000, RX to 100, Smith chart).
4. **Output**: Save the resulting plot to a file specified by the user.
5. **Reference**: Use `/home/dn/WORK/Python/QR/pts2graph.py` as a reference for plotting.

## Touchstone Format
The Touchstone format includes:
- A comment line starting with `!`.
- A column header line starting with `#`.
- Data lines with frequency and values (e.g., `! Touchstone file generated by match-cli.py` followed by `# MHz Z RI R 50`).

### Supported Formats
- **S,RI**: Real and imaginary parts of the S-parameter.
- **S,MA**: Magnitude and angle of the S-parameter.
- **S,DB**: Magnitude in decibels (dB) of the S-parameter.
- **Z,RI**: Real and imaginary parts of the impedance (Z).

## Script Structure

### 1. Input Handling
- Accept input from stdin or a file with `.s1p` extension.
- Parse the Touchstone data into a structured format.

### 2. Format Detection
- Automatically detect the format by examining the column headers.
- Support `S,RI`, `S,MA`, `S,DB`, and `Z,RI` formats.

### 3. Plot Types
- **SWR to 10**: Plot SWR (Standing Wave Ratio) up to 10.
- **SWR to 2**: Plot SWR up to 2.
- **S11**: Plot S11 parameter in dB.
- **RX to 1000**: Plot RX (Resistance and Reactance) up to 1000.
- **RX to 100**: Plot RX up to 100.
- **Smith Chart**: Plot a Smith chart.

### 4. Output
- Save the plot to a file specified by the user.
- Support common image formats (e.g., PNG, JPEG, SVG).

### 5. Command-Line Interface
- Use `argparse` to handle command-line arguments.
- Support `-h` or `--help`.
- Accept input file or stdin.
- Require `--type` and `--output`.

## Example Usage

### Plot SWR to 10
```bash
python tt-plot.py --type swr10 --output plot.png < data.s1p
```

### Plot Smith Chart
```bash
python tt-plot.py --type smith --output smith_chart.png data.s1p
```

### Plot RX to 100
```bash
python tt-plot.py --type rx100 --output rx_plot.png data.s1p
```
